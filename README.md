# E-commerce Sales Analysis 📊

## Project Overview
An exploratory data analysis project focused on understanding customer behaviour, sales performance, product categories, seasonal trends, and shipping preferences.

## Tools & Technologies
- Python (Pandas)
- SQL
- Google Sheets
- Data Visualization

## Dataset
- 3,900 records
- 18 original columns
- 37 missing review ratings

## Key Insights
- **Total Revenue:** $233,081
- **Total Orders:** 3,900
- **Average Purchase:** $59.76
- **Average Rating:** 3.75
- **Top Category:** Clothing ($104,264)
- **Top Season:** Fall ($60,018)
- **Top Age Group:** Young ($62,143)
- **Subscription Rate:** 27%

## Analysis Performed
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Segmentation
- Category & Seasonal Analysis
- Shipping & Rating Analysis
- SQL-Based Data Analysis

## Key Takeaways
- Clothing contributes approximately 45% of total revenue.
- Only 27% of customers have subscriptions.
- Young customers contribute the highest spending.
- Free Shipping generates the highest revenue.
- Standard Shipping has the highest average rating.

## Conclusion
The analysis identifies key opportunities to improve customer subscriptions, strengthen product categories, and enhance customer satisfaction through data-driven decisions.
